# Cyrene Dialogue Catalogue

**Repository:** `KERUIWA/uib-online-library`  
**Website page:** `hsr.html`  
**Audio folder:** `assets/audio/`  
**Last catalogue update:** 2026-11-13

This is the human-readable source catalogue for Cyrene's dialogue. English is the on-screen text. Japanese is the translation/reference text; the EN/JP toggle changes voice audio only.

## Audio filename convention

- English voice: `.en.mp3`
- Japanese voice: `.jp.mp3`
- Main dialogue: `CY-<ID>-01.<lang>.mp3`
- Choice replies: `CY-<ID>-R01.<lang>.mp3`, `CY-<ID>-R02.<lang>.mp3`
- Choice labels are displayed but are not voiced.
- **Recorded** means the matching file currently exists in `assets/audio/`.
- **Planned** means the filename is reserved for a future recording.
- **No voice planned yet** means the encounter is intentionally text-only for now.

## 13. Reconciliation and 24-hour awkward phase

**Status:** Implemented. After Cyrene's angry dialogue has finished, click Mem five times to reconcile. The click count persists across refreshes.

On the fifth click:
- The angry lock is cleared.
- Cyrene delivers the reconciliation dialogue below.
- A **24-hour real-time awkward phase** starts immediately and its start timestamp is saved in local storage.
- Refreshing the page does not restart the timer.
- During the phase, regular encounter main dialogue uses the awkward versions below. These variants are text-only for now, so no mismatched old voice recording is played.
- When 24 hours have elapsed, the next regular encounter automatically uses the original dialogue again.
- If Cyrene becomes angry again and is reconciled again, the 24-hour timer restarts from that new reconciliation.

### Reconciliation dialogue

**EN:**  
"...You really came back. Five times, no less. I'm still hurt, you know... but I can see you're trying. I'll give you another chance. Just... don't make me regret it, okay?"

**JP:**  
「……本当に戻ってきたのね。しかも、5回も。まだ傷ついてるんだからね……でも、ちゃんと向き合おうとしてくれてるのはわかった。もう一度だけ、チャンスをあげる。だから……後悔させないでよね。」

**Audio:** Not recorded yet. No audio filenames assigned.

## Recording / implementation notes

1. Keep all visible dialogue and choice labels in English. The language toggle changes audio only.
2. Japanese text in this catalogue is for translation/reference and Japanese voice recording.
3. Do not rename an audio file without updating the matching reference in `hsr.html` and this catalogue.
4. New encounters are intentionally unvoiced for now. Their filenames above are reserved suggestions, not existing files.
5. The current five-Mem-click reconciliation is implemented. The more elaborate reconciliation quest and the 72-hour post-redemption dialogue phase remain future ideas.
